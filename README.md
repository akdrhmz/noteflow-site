## Düzenleme

Sayfalar bu deponun kökünde tek dosya hâlindedir; bağımlılık, derleme adımı veya harici kaynak (CDN) kullanmazlar. Değişiklik için ilgili `.html` dosyasını düzenleyip `main` dalına gönderin — GitHub Pages otomatik olarak yeniden yayınlar.
